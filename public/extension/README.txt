عامل اجرایی مرورگر پلتفرم RasaWeb Messaging Hub
Central Panel = مغز مدیریت | این افزونه = Browser Worker

────────────────────────────────────────
نصب (Load Unpacked)
────────────────────────────────────────

۱. این پوشه را استخراج کنید (اگر ZIP دانلود کرده‌اید)
۲. در کروم به آدرس  chrome://extensions  بروید
۳. Developer Mode را از بالا-راست روشن کنید
۴. روی  Load unpacked  کلیک کنید و این پوشه را انتخاب کنید
۵. آیکون RasaWeb Agent در نوار افزونه‌ها ظاهر می‌شود

────────────────────────────────────────
جفت‌سازی با پنل (Pairing)
────────────────────────────────────────

۱. در پنل مرکزی RasaWeb → منوی «عامل مرورگر» → «Browser Workers»
۲. دکمه «افزودن Worker» → کد اتصال مثل RX-28491 صادر می‌شود (۱۵ دقیقه اعتبار)
۳. روی آیکون افزونه کلیک کنید
۴. آدرس پنل مرکزی + کد اتصال را وارد کنید
۵. تمام! Worker در پنل 🟢 متصل نمایش داده می‌شود

────────────────────────────────────────
امکانات
────────────────────────────────────────

• Popup: وضعیت اتصال، Worker، وظایف فعال، صف، Open Control Panel
• Side Panel: Context صفحه جاری (پلتفرم، چت، نوع چت، نشست) + اجرای سریع Actionها
• Agent Loop: مشاهده → درک → تصمیم → اجرا → بررسی → گزارش
• Platform Adapter: واتساپ، تلگرام، روبیکا، بله، ایتا، سروش‌پلاس
• تشخیص نوع چت: خصوصی / گروه / کانال / بات / تجاری
• ارسال متن، عکس، فایل، عکس+کپشن، ساخت گروه (طبق قابلیت هر سرویس)
• Safety Layer: تطابق پلتفرم/اکانت/چت قبل از اجرا
• Human-in-the-loop: برای CAPTCHA / 2FA / Security Check عامل متوقف می‌شود
• Event Log کامل روی پنل + گزارش وضعیت لحظه‌ای

────────────────────────────────────────
امنیت (Manifest V3)
────────────────────────────────────────

• بدون remotely hosted code — همه کدها در همین پکیج
• توکن جفت‌سازی فقط در chrome.storage.local مرورگر شما
• توکن خام هرگز به لاگ‌ها منتقل نمی‌شود
• مجوزها بر اصل حداقل دسترسی — مجوز پنل فقط هنگام اتصال

────────────────────────────────────────
نکته مهم
────────────────────────────────────────

این افزونه فقط عملیات مجاز و پشتیبانی‌شده هر سرویس را انجام می‌دهد و
برای دور زدن CAPTCHA، Anti-Bot، محدودیت ارسال یا Ban طراحی نشده است.
در مواجهه با موانع امنیتی، وضعیت «نیاز به اقدام انسانی» گزارش می‌شود.
